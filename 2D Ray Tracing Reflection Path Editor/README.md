# 二维平面光线反射模拟系统

基于 React + Express + better-sqlite3 开发的光线追踪模拟编辑器。

## 功能特性

### 核心算法
- **射线追踪**：递归追踪光线在障碍物间的反射路径
- **最近交点搜索**：精确计算光线与线段的交点
- **菲涅尔系数**：模拟反射与折射的能量分配
- **全内反射**：当入射角超过临界角时的全反射

### 三种材质
1. **镜面反射**（青色）：完美镜面反射
2. **透明折射**（绿色）：支持折射率调节的折射材质
3. **完全吸收**（红色）：吸收所有入射光线

### 动画效果
- ✨ **脉冲光点**：沿光路移动的动态光点
- 🔵 **能量衰减圆环**：反射点的波纹扩散动画
- 🌑 **阴影区域灰度渐变**：多层阴影扫描效果
- 💫 **镜面高光扫描线**：随时间变化的高光动画
- ❌ **错误路径红色闪烁**：路径逃逸时的闪烁提示

### 内置预设场景
1. **平行光束进入半圆形透镜的聚焦发散异常**
   - 展示透镜的聚焦与发散效果
   - 可观察光路分裂与能量分配

2. **多反射面形成闭合光路的无限循环检测**
   - 展示光线在闭合空间的多次反射
   - 紫色高亮标记可能的循环点
   - 观测性能随反射次数增加而下降

3. **完全吸收边界的能量突然归零**
   - 展示吸收边界的效果
   - 光线在吸收面上的突然终止

4. **掠入射时的全反射临界角可视化**
   - 展示全内反射现象
   - 临界角附近的光路变化

## 可观测现象
- 反射阶数过高时的**性能下降**（计算时间显著增加）
- 浮点误差导致的**路径逃逸**（红色闪烁标记）
- 折射率边界处的**光线分裂丢失**
- 吸收边界未触发计算的**暗区漏光**

## 安装与运行

### 1. 安装依赖
```bash
npm run install-all
```

### 2. 启动后端服务器
```bash
npm run server
```
服务器运行在 http://localhost:3001

### 3. 启动前端（新终端）
```bash
npm run client
```
前端运行在 http://localhost:3000

## 使用说明

### 工具栏
- **障碍物工具**：在画布上拖拽绘制线段障碍物
- **光源工具**：点击画布放置点光源

### 材质选择
- 可在绘制前选择障碍物材质
- 透明材质可调节折射率（1.0 - 2.5）

### 参数调节
- **最大反射次数**：1 - 50，建议不要超过20以避免性能问题

### 预设场景
点击右侧预设场景按钮，一键加载演示场景。

## 技术栈

### 后端
- **Express.js**：Web 服务器
- **better-sqlite3**：数据库存储
- 核心算法：自定义射线追踪实现

### 前端
- **React 18**：UI 框架
- **Canvas API**：2D 渲染与动画
- requestAnimationFrame：流畅动画循环

## API 接口

- `POST /api/trace` - 光线追踪计算
- `GET /api/presets` - 获取预设场景列表
- `GET /api/presets/:index` - 加载指定预设场景
- 完整的场景/障碍物/光源 CRUD 接口
