# 二维骨骼系统编辑器

基于 Vue + Koa + SQLite3 开发的逆向运动学骨骼动画编辑器，支持 CCD 和 FABRIK 两种求解算法。

## 功能特性

### 核心功能
- ✅ 骨骼树结构创建与编辑
- ✅ CCD (Cyclic Coordinate Descent) 逆向运动学求解器
- ✅ FABRIK (Forward And Backward Reaching Inverse Kinematics) 求解器
- ✅ 关节角度约束设置
- ✅ 蒙皮权重与网格变形
- ✅ 误差阈值与最大迭代次数调节

### 动画效果
- ✅ **弹簧插值动画** - 骨骼变形时的平滑弹性效果
- ✅ **轨迹路径动画** - 末端执行器移动的蓝色轨迹线
- ✅ **误差下降条形图** - 求解过程中误差收敛的可视化
- ✅ **约束违反闪烁** - 关节超出约束范围时的红色闪烁警告
- ✅ **姿态渐变动画** - 关键帧之间的平滑插值过渡

### 预设场景
1. **预设一 - 两足生物腿部** - 3节骨骼，髋关节、膝关节、踝关节约束
2. **预设二 - 机械臂抓取** - 3节机械臂，适合圆形区域抓取演示
3. **预设三 - 多分支触手** - 5节触手，严格角度约束，演示约束违反
4. **预设四 - 蒙皮权重极端不均衡** - 演示权重极值导致的网格畸变塌陷

### 可观察现象
- 📍 **振荡收敛** - 目标点超出可达范围时的末端振荡现象
- 🔮 **网格塌陷** - 权重极值(0.99/0.01)引起的网格畸形变形
- 🎯 **精度偏移** - 迭代次数过少时末端无法完全贴合目标点
- ⚠️ **约束警告** - 关节角度超出限制时的视觉反馈

## 安装与运行

### 1. 安装依赖

```bash
# 安装后端依赖
cd server
npm install

# 安装前端依赖
cd ../client
npm install
```

### 2. 启动后端服务

```bash
cd server
npm start
# 或使用开发模式（自动重启）
npm run dev
```

后端服务将在 http://localhost:3000 启动

### 3. 启动前端开发服务器

```bash
cd client
npm run serve
```

前端应用将在 http://localhost:8080 启动

## 使用说明

### 基本操作
1. **拖动目标点** - 点击并拖动红色十字目标点
2. **选择求解器** - 在求解器面板切换 CCD/FABRIK 算法
3. **调整参数** - 修改最大迭代次数和误差阈值
4. **观察收敛** - 查看误差下降条形图的变化

### 测试现象

#### 1. 振荡收敛现象
- 选择「预设一 - 腿部」或「预设二 - 机械臂」
- 将目标点拖动到骨骼链总长度之外的远处
- 观察末端执行器在极限位置附近的振荡
- 可以尝试不同迭代次数观察收敛效果

#### 2. 网格畸变塌陷
- 选择「预设四 - 蒙皮」
- 点击「生成极值权重」按钮
- 拖动目标点移动骨骼
- 观察网格顶点因权重极端不均衡导致的扭曲塌陷

#### 3. 迭代精度偏移
- 选择任意预设
- 将最大迭代次数设置为较小值（如 1-5）
- 拖动目标点到新位置
- 观察绿色末端执行器与红色目标点之间的明显偏移
- 逐渐增加迭代次数，观察精度如何提升

#### 4. 约束违反警告
- 选择「预设三 - 触手」（具有严格的角度约束）
- 将目标点拖动到需要关节大幅转动的位置
- 观察骨骼变为红色并闪烁
- 在结果面板查看约束违反次数统计

### 动画控制
- **弹簧阻尼** - 控制动画的衰减速度（0=无阻尼，1=立即停止）
- **弹簧刚度** - 控制动画的弹性强度（值越大响应越快）
- **播放速度** - 控制关键帧动画的播放速率

## API 接口

### 求解 IK
```
POST /api/ik/solve
{
  "bonesData": [...],       // 骨骼数据数组
  "target": {x, y},        // 目标位置
  "solverType": "ccd|fabrik",
  "maxIterations": 100,
  "threshold": 0.1
}
```

### 预设管理
```
GET  /api/presets          // 获取所有预设
GET  /api/presets/:name    // 获取指定预设
POST /api/presets          // 保存预设
```

### 关键帧
```
GET  /api/keyframes/:presetId    // 获取预设的关键帧
POST /api/keyframes               // 保存关键帧
```

### 蒙皮权重
```
POST /api/mesh              // 保存网格和权重
GET  /api/mesh/:presetId    // 获取网格和权重
```

## 算法说明

### CCD 算法
循环坐标下降法，从末端骨骼开始逐一向根节点迭代，每次只调整一个关节的角度，使末端尽可能接近目标。适合关节数量较少的情况。

### FABRIK 算法
向前向后到达法，通过两次遍历（先从末端到根节点，再从根节点到末端）调整各关节位置。收敛速度更快，解更自然。

## 技术栈

- **前端**: Vue 3 + Vuex + Vue Router + Element Plus + Canvas 2D
- **后端**: Koa 2 + @koa/cors + koa-bodyparser
- **数据库**: SQLite3
- **动画**: requestAnimationFrame + 弹簧阻尼物理模拟
