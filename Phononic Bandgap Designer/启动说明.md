## 使用指南

### 基本操作
1. **选择预设** - 点击顶部预设卡片快速加载经典结构
2. **调节参数** - 使用左侧面板的滑块和下拉菜单调整参数
3. **重新计算** - 点击"🚀 计算能带结构"按钮
4. **切换视图** - 使用中央顶部标签切换不同可视化模式
5. **3D交互** - 在晶格视图中可以：
   - 鼠标拖拽：旋转视角
   - 滚轮：缩放
   - 右键拖拽：平移

### 能带图解释
- **横坐标**：布里渊区高对称点路径（Γ → X → M → Γ）
- **纵坐标**：归一化频率 ωa/(2πc)
- **彩色曲线**：不同能带
- **紫色高亮区域**：带隙（禁带）

## 故障排除

### 前端无法加载
- 确认已安装依赖：`cd frontend && npm install`
- 检查端口5173/5174是否被占用
- 查看浏览器控制台错误信息

### 后端无法启动
- 确认已安装依赖：`cd backend && npm install`
- 检查端口3002是否被占用
- 查看终端错误日志
