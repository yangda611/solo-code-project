# 🧬 HP 格点模型蛋白质折叠可视化系统

基于 **Nuxt 3 + Three.js + WebGL** 技术栈开发的实时蛋白质折叠模拟可视化平台。

## ✨ 核心功能

### 🎯 模拟引擎
- **Metropolis 蒙特卡洛算法**：基于玻尔兹曼概率的构象采样
- **模拟退火优化**：温度梯度下降搜索天然态
- **格点移动类型**：末端摆动、曲柄运动、滑块移动
- **实时统计**：能量、温度、接触数、接受/拒绝率

### 🎨 三维可视化
- **Three.js WebGL 渲染**：高性能 3D 场景
- **残基着色**：红色=疏水(H)，蓝色=极性(P)
- **接触高亮**：绿色发光效果显示疏水接触
- **轨道控制**：旋转、平移、缩放交互
- **Bloom 后处理**：科幻发光效果
- **格点辅助线**：空间定位参考

### 📊 数据图表
- 自由能变化曲线
- 模拟退火温度曲线
- 疏水接触数统计
- 实时状态面板

### 🎬 四大预设场景
1. **快速两态折叠**：两端疏水簇，观察清晰的两态转变
2. **玻璃态动力学陷阱**：快速冷却导致亚稳态冻结
3. **螺旋结构偏好**：周期性序列偏好螺旋构象
4. **多域独立折叠**：两段疏水域分别折叠

### 💾 数据持久化
- **IndexedDB 存储**：保存低能构象快照
- **折叠轨迹记录**：完整模拟过程存档

## 📐 模型理论

### HP 格点模型
蛋白质链由疏水(H)和极性(P)残基组成，在三维立方格点上折叠。能量函数：
```
E = -ε × N_HH
```
其中 N_HH 为疏水残基的空间接触对数（非共价键）。

### Metropolis 准则
新构象接受概率：
```
P(accept) = min(1, exp(-ΔE / kT))
```
ΔE 为能量变化，k 为玻尔兹曼常数，T 为当前温度。
