# 圆柱绕流与流致振动耦合模拟系统 - 产品需求文档

## 1. 产品概述
基于二维不可压Navier-Stokes方程的实时流固耦合数值模拟系统，通过WebGL与Canvas 2D实现高性能可视化，面向计算流体力学教学与研究场景，展示涡激振动、锁定共振、驰振失稳等复杂物理现象。

### 1.1 产品目标
- 提供浏览器端实时CFD模拟，无需安装专业软件
- 展示冯·卡门涡街、流致振动等经典流体力学现象
- 支持参数化研究（雷诺数、结构参数等）
- 通过可视化帮助理解流固耦合机制与数值模拟特性

### 1.2 目标用户
- 流体力学专业学生与教师
- 计算力学研究人员
- 工程设计人员（风工程、海洋工程等）
- 对计算物理感兴趣的爱好者

## 2. 核心功能

### 2.1 功能模块

| 模块名称 | 功能描述 |
|---------|---------|
| CFD求解器 | 基于投影法的二维不可压Navier-Stokes方程求解，交错网格离散 |
| 结构求解器 | 单自由度弹性支撑圆柱运动方程求解，与流场双向耦合 |
| WebGL可视化 | 涡量场实时渲染，支持伪彩色映射与流线追踪 |
| Canvas可视化 | 李萨如图、频谱瀑布图、分岔图等多维度数据展示 |
| 参数控制面板 | 雷诺数、圆柱直径、弹簧刚度、阻尼比等参数调节 |
| 场景预设 | 四种典型场景一键加载：低雷诺数稳定、临界涡脱落、锁定共振、驰振失稳 |
| 数据持久化 | localStorage保存流场快照与位移时程数据 |

### 2.2 页面结构

| 页面名称 | 主要功能 |
|---------|---------|
| 主模拟页面 | 涡量场主画布 + 参数控制面板 + 多维度可视化面板 |

## 3. 核心功能详细说明

### 3.1 流体求解核心
- **控制方程**: 二维不可压Navier-Stokes方程
- **数值方法**: 投影法（分步法）
- **网格系统**: 交错网格（MAC网格）
- **边界条件**: 入流Dirichlet、出流Neumann、壁面无滑移
- **时间积分**: 显式Runge-Kutta或半隐式格式

### 3.2 结构求解核心
- **运动方程**: 单自由度受迫振动方程
- **耦合方式**: 双向流固耦合（流场力→结构位移→网格变形→流场更新）
- **数值方法**: Newmark-β法或中心差分法

### 3.3 可视化模块

#### 3.3.1 主可视化（WebGL）
- 涡量场伪彩色渲染（蓝-白-红配色表示负-零-正涡量）
- 圆柱位置与运动轨迹实时更新
- 速度矢量场可选叠加显示

#### 3.3.2 辅助可视化（Canvas 2D）
1. **横向振动轨迹李萨如图**: 位移-速度相平面图
2. **升力系数频谱瀑布图**: 随时间演化的频谱分析
3. **尾流速度亏损恢复曲线**: 尾流中心线速度沿程分布
4. **振幅-约化速度分岔图**: 展示锁定区间与分岔特性

### 3.4 预设场景
1. **低雷诺数稳定附着预设** (Re ≈ 10)
   - 雷诺数：10
   - 无明显涡脱落
   - 对称稳定流动

2. **临界涡脱落预设** (Re ≈ 100)
   - 雷诺数：100
   - 规则卡门涡街
   - Strouhal数≈0.2

3. **锁定共振预设**
   - 结构固有频率接近涡脱落频率
   - 大振幅振动
   - 频率俘获现象

4. **驰振失稳预设**
   - 高雷诺数
   - 负气动阻尼
   - 振幅持续增大

### 3.5 数值现象展示
- 高雷诺数下二维假设失效导致的涡量场三维展向不稳定性被错误抑制
- 流固耦合时间步长不匹配引发的能量非物理传递与数值发散
- 锁定区内涡脱落频率被结构振动频率俘获导致的拍频消失
- 大振幅时网格随体运动产生的扭曲畸变与雅可比行列式变号

## 4. 用户界面设计

### 4.1 设计风格
- **主题**: 科技感深色主题，流体动力学专业风格
- **主色调**: 深蓝(#0a1628) + 青色(#00d4ff) + 橙色(#ff6b35)
- **字体**: JetBrains Mono（代码/数值）+ Inter（界面文本）
- **布局**: 网格布局，主画布占70%宽度，控制面板与辅助可视化占30%
- **动效**: 平滑过渡动画，数据更新渐变效果

### 4.3 交互设计
- 滑块实时更新参数并重启模拟
- 预设按钮点击立即加载对应参数配置
- 辅助可视化支持Tab切换不同分析图表
- 保存/加载按钮触发localStorage数据操作
- 鼠标悬停显示参数说明与物理意义

## 5. 技术约束
- 纯前端实现，无后端依赖
- 实时性能目标：≥30 FPS
- 支持主流现代浏览器（Chrome 90+, Firefox 88+, Safari 14+）
- 响应式布局，适配桌面端屏幕

## 6. 性能要求
- CFD网格分辨率: 256×128 或 512×256（可选）
- WebGL渲染使用GPU加速
- 数据可视化使用离屏Canvas优化
- 内存占用控制在500MB以内
